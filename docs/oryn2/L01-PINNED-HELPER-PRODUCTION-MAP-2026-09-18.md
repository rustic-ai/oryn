## Confirmed source fix during this review

Loading lane's declared-type review identified element-specific source eligibility. `EmbeddedContentKind::loads_source` now distinguishes absent/exactly empty object data from whitespace data, and absent embed src from explicitly empty src. The HTML parser and parsed-snapshot event producer use the shared predicate. Object ancestor fallback checks exact emptiness, so whitespace resource URLs do not activate fallback prematurely. Native regression sources cover the predicate, parser events and nested fallback. Loading owns dynamic/native source normalization and transport/representation reconciliation; these are part of the embedded dependency closure, not a guessed codec fix.
