Source review and generation, September 16. **No build/test execution.** This inventories every top-level `ContextServiceRequest` variant; it is not an assertion that every nested protocol or document-lifetime path is complete. ## Shared enforcement and publication

The process router verifies the entire WorkerRoute, admits the operation under RouteAuthority, then calls ParentContextService. The service holds a temporary BrowserContext owner for dispatch and rejects requests after shutdown. Most handlers also compare page/source identity against the service's fixed page. These checks authenticate a page environment; they do not automatically authenticate a particular frame document. Explicit Creator checks are recorded below.

All IPC replies use version, route and correlation validation and a ResponseReceipt. `Publications` retains response custody and dispatch capacity until accepted receipt or disconnect. Ordinary value replies require no resource rollback. Capability replies need explicit cleanup ownership. Stateful side effects (storage writes, navigation, clipboard writes) are not undone merely because a reply is lost; retries therefore require operation-specific semantics rather than blanket rollback.

`CancelScriptLoad` is the only top-level router exception that permits exact original retired-route cancellation without new network authority. Existing shared-memory Release/CancelAdmission permits retained native capability operations inside a live route, but that alone does not imply all retired-route cancellation is accepted.
