## Notification scope evidence

A full pinned-checkout literal source search for `new Notification`, `Notification.requestPermission`, `showNotification` and `getNotifications`, classified with the fixed policy, found 49 files: **1 Core, 3 Necessary, 45 Extended**. The one Core file is `html/infrastructure/safe-passing-of-structured-data/shared-array-buffers/serialization-via-notifications-api.any.js`. It has no script/helper dependency and only constructs notifications to assert storage serialization failure. Current repository benchmarks, scripts and application fixture sources contain no notification calls other than generated regressions.

`web_notifications.rs` therefore generates the required native constructor/options/data path plus stable fields, permission reads and asynchronous error when no display adapter is available. It does **not** claim native OS display, interactive Notification permission prompting or persistent service-worker notifications. Those broader capabilities remain outside this W-03 dependency completion claim; their Necessary/Extended sources remain in the attached inventory. No unsupported API is treated as a passing test.
