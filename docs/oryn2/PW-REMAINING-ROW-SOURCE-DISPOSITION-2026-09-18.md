## Confirmed page teardown fan-out correction

`BrowserContext::retire_page_agents` previously returned on deferred-page flush
failure before media/platform/cache/service/agent/IDB/socket cleanup. It also
returned from agent/hub detachment failure before IDB/socket cleanup. It now
retains the deferred error, completes every independent cleanup stage, and
returns the original deferred failure after the remaining work. Detached failed
agent batches keep existing retry custody. The regression source
`failed_deferred_flush_still_retires_page_transactions_and_preserves_sibling`
injects a failed deferred registry, asserts exact target transaction retirement,
preserves a sibling entry, and checks retry does not resurrect released custody.
No execution occurred.
