## Response delivery recovery

Executable fetch activity now selects its own root document and native descendant environments instead of all unparked fetches in a shared agent. Per-environment admission records preserve short completed requests; retirement removes the exact environment's record and parked environments are excluded from the snapshot. The shared host scheduler retains its broader pending-work query. `root_fetch_activity_ignores_other_environment_admissions_and_releases_retired_records` covers admission isolation and retirement; the host promise regression also checks root-scoped pending and completed snapshots. Selected-frame and full restored-document integration remain open.

Before invoking a fetch resolver, native string argument allocation must succeed. Failure retains the original PendingFetch and owned FetchCompletion in the deferred queue; no request is reissued. `fetch_delivery_allocation_failure_retains_response_without_refetch` injects failure for both successful and failed broker responses, asserting one request, retained promise/response and one eventual delivery. Additional success/error branches retire the environment before retry and verify pending/deferred custody is removed without a phantom in-flight marker or refetch. This is generated source, not an executed result. Resolver-entry/termination and parked-context recovery still require complete reconciliation.

## Native broker stream release

`IdentityRead` now releases its request identity on a successful EOF read into a nonempty buffer, even if the exhausted response reader remains retained. Empty-buffer reads do not imply EOF; read failures retain ownership because `Read` errors such as Interrupted can be retried. Dropping an unread or failed reader transfers its identity to the existing cancellation retry owner instead of releasing it immediately. No destructor waits for transport acknowledgement. `exhausted_stream_releases_identity_before_reader_drop` covers data, empty-buffer reads, EOF, repeated EOF and the owner drain barrier. `abandoned_stream_retains_identity_until_cancellation_acknowledgement` covers unread and interrupted bodies, duplicate-ID rejection while cancellation is pending, and drain completion only after the original native identity is acknowledged. These are unrun regression sources. Full routed/standalone activity aggregation remains open.

## Page broker activity integration

Background refresh admission now retains the native identity chain through a captured ownership context. The deferred broker adapter explicitly installs that context; absence clears any ambient owner instead of inheriting an unrelated request. The ownership helper restores the previous context after normal return and panic, with nested absent-context regression coverage. This source review preserves document-specific activity rather than using shared cache-wide counts. Full cache/loader qualification remains unexecuted.

Native broker identity accounting now exposes a read-only activity snapshot. Admission, terminal release and snapshot reads use the same lock order; completed requests between checkpoints retain their timestamp. PageState retains a page transport and creates a separate broker request scope for each document before any loader receives a clone. Network-idle checks the active document scope alongside host/resource activity. The body-drop cancellation regression also checks that activity remains nonzero until acknowledgement. This covers loaders using the active document broker; it does not establish coverage for independently created brokers or selected-frame routing.

The wait uses the latest page, broker or scoped-resource timestamp after rejecting active ownership. A terminal native record can therefore establish quiet even when a failed request never produced a response trace and left the legacy page timestamp unset. The standalone regression includes this missing-trace recovery while retaining the exhausted response object.

Context-backed document construction now installs a document-specific SharedContextClient activity view in both standalone and shared-agent constructors. Its resource jobs still enter the shared route teardown registry; retirement through any view seals the original route and waits for jobs from all documents. Cached executables retain their own view when parked and restored. The delayed HTTP release regression checks that the owning document and shared route remain active until acknowledgement while a replacement document's snapshot stays empty. Full producer coverage and selected-frame semantics remain open.

## Removed superseded paths

- OIL's repeated whole-wait retry loop and authored drain-helper calls.
- Sticky historical NetworkIdle as the predicate's authority.
- Decoder-only frame activity lease; prepared-response cleanup ownership spans the whole lifetime instead.
- Header-acceptance disarming of network cleanup: `ContextNetworkReply::accept` and `Ticket::accept` were removed. EOF uses the existing cancellation-aware finish path; header acceptance retains the stream owner.

## Uncommitted standalone scope cancellation review

The standalone candidate broker is owned by the loader/completion until commit transfers it into the realm. A stale completion, no-content/download early return, failed publication or failed commit drops that candidate scope. `IdentityBroker::drop` signals each retained background cancellation flag immediately and schedules acknowledged native cancellation without blocking the destructor. Leases retain ancestor activity until background operations release them. Generated regression `dropping_uncommitted_scope_signals_background_and_retains_ancestor_until_ack` holds a refresh behind a refused cancellation, drops the candidate, checks immediate cancellation and sibling isolation, then acknowledges cleanup and drains ancestor custody. This is unrun source coverage; the complete parent-service cancellation and runtime retirement inventory remains open.

## Selected-frame command regression source

`selected_frame_network_idle_tracks_its_body_without_blocking_siblings` exercises the full scoped WorkerRequest path with two real srcdoc documents. It retains an unread broker response in one frame, requires its zero-deadline wait to fail while the sibling succeeds, consumes EOF, rejects immediate reuse of the old quiet interval, and eventually observes native NetworkIdle through the scoped command. The subsequent root/selected-frame review removed trace-based timing updates entirely: unattributed, author-replaceable diagnostic records cannot establish network activity. The separate forged-trace regression covers this boundary for root waits. This complements the registry/endpoint ownership tests and remains unbuilt/unrun.
