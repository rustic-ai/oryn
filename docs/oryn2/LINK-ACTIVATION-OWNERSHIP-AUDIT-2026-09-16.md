# Link activation ownership source audit

Status: generation/source inspection only. No build or test execution.

## Generated integration

The accepted click queue owns `LinkNavigation` instead of relying on a later host DOM lookup. Capture resolves the URL against the source document base and encoding, retains the exact source wrapper/window, and freezes target/base-target, relation/referrer and download attributes. Local destination identity uses the existing root generation or parent/frame connection receipt, so rename cannot redirect the accepted navigation and removal cannot substitute a new named frame.

The shared event dispatcher now selects and retains the link activation element before listeners run. Selection follows assigned slots, respects non-composed shadow boundaries, and uses the same native related-target identity and retargeting exclusions as the listener path. Its tracked wrapper follows adoption; href is observed after listeners, allowing href additions while preventing ancestor substitution after href removal. Only MouseEvent-family click activation queues links, and non-bubbling descendant clicks do not activate ancestors. Separate authored/device/label-forwarded queue calls have been removed; there is one production queue call in activation finish. Native pointer, keyboard and user-input permission handling also resolves moved wrappers after callbacks. Existing label/control suppression remains. Inert document nodes cannot capture a live-document hyperlink navigation; detached nodes belonging to the active document may still do so.

The native host no longer climbs link ancestors, reads href/target/rel/download attributes, parses relative URLs, or resolves local names when draining a click. Existing retained action queues preserve this snapshot across host retries. Form transactions use their already captured URL/target/source through the same consumer.

Regression sources cover anchors and areas, mutation inside click versus after click, document-base changes, adoption and original source wrapper identity, base target selection, destination rename/removal, canceled clicks, and noreferrer precedence over explicit unsafe-url policy. Additional sources cover moving the clicked descendant between links during dispatch, href addition/removal, MouseEvent versus Event activation, non-bubbling selection and closed-slot/non-composed shadow paths.

The link/form `OpenPage` response now consumes `RelatedRootAdmission` through a typed host entry into the existing auxiliary-root creator. Its native actor can claim the published initial root just as for window.open; existing-page responses cannot supply a new-root admission. The existing synchronous-global/DOM/root-retirement regression now exercises this host entry. This repairs delivery of the admission, not acceptance-time target creation.

Local target capture and parent OpenPage selection now apply the same noopener target normalization. Named destinations become fresh contexts, while empty/self/parent/top defaults retain existing-context semantics. New noopener contexts are unnamed. The helper is in the shared navigation module so parent-only builds do not depend on V8 bindings. Regression sources cover native local frame reuse rejection for links/forms, shared reserved-target rules, and parent popup name/opener/group initialization.

Image-map activation now captures a suffix for HTML anchor clicks targeting an `ismap` image. Trusted clicks use image-relative client coordinates with nonnegative clamping; untrusted clicks use `?0,0`. The suffix is appended after URL serialization and retained for normal/download navigation. Generated regression sources cover native pointer coordinates, untrusted supplied coordinates, mutation after activation and placement after an existing fragment.

Existing local targets, including download requests, now perform native Navigation admission synchronously in the destination context during link activation. Parent-backed Location authorization supplies the immutable script-navigation source authority for ordinary navigation; downloads use the dedicated parent download authorization method. The captured admission retains destination realm, operation token, history destination and authority. Host draining validates the token and schedules loading without firing NavigateEvent again; reentrant/superseding/canceled requests cannot replay an old admission. No-op canceled link transactions are not enqueued. Regression sources assert event order before click returns, single dispatch, reentrant replacement and cancellation. Host suffix-retry regression sources now use planned forms to exercise deferred execution rather than depending on obsolete link timing.

Parent queued frame navigation now uses `NavigateSelectedFormWindow`, which resolves the current document in the previously selected native frame connection before delegating to the ordinary form-navigation consumer. Frame identity requires matching parent realm, frame node, non-null connection generation and native frame token; document realm/generation/URL changes alone do not replace that navigable. Removed/reinserted or retired frames are rejected. Existing exact-document automation commands retain their semantics. Regression sources cover document replacement, parent/connection/token changes, absent identity and command payload preservation. The worker protocol is now 15 because this adds a worker frame command (context 47 / agent IPC 16 remain the combined generation contracts).

## Parent selected-target receipts

OpenPage can now return and consume an authenticated target receipt. Its payload binds the BrowserContext, source page, destination page and selected frame connection. The native receiver resolves current document metadata for that connection, then checks source-document navigation policy before queuing. Target names do not participate in consumption. Source provenance may be retained or inert metadata; the receipt itself grants no navigation permission. The authored compatibility bridge strips receipt fields in both directions.

Regression sources now distinguish navigable selection from exact-document automation: a selected frame survives commit and rename, while stale automation observation fails and removal/replacement invalidates selection. Tampered destination bytes, wrong source/context and oversized envelopes are rejected. These sources have not been executed.

Native link/form capture now requests selection through a host-only function pointer before queuing the accepted action. Selection-only OpenPage validates relationship policy and creates/selects the destination without starting its URL load; the native callback publishes related auxiliary roots. Accepted transactions retain the receipt and the default-action consumer returns it. Denied selection produces no new action and does not supersede a previously planned form. Regression sources cover mutations after selection, denied replacement and the parent selection-only route. Synchronous new/remote NavigateEvent admission and full selection-order/lifecycle reconciliation remain open.

## Same-actor selected targets

The native selection result includes the parent page identity and an optional local auxiliary realm. Link capture resolves that realm, obtains script authority bound to the distinct source and destination pages, and performs destination Navigation admission immediately. Accepted actions retain the native operation; consumption schedules it in the destination realm without repeating parent selection. A retired admitted local target is dropped. Initial about:blank retains the Navigation API rule disabling entries/events; its regression checks admission custody rather than expecting a navigate event.

Remaining source review: same-actor post-commit and actor-polling/reentrancy paths; remote admission must use destination-owned bounded operation records with one-time consume, preserving source wrapper/FormData custody where visible. Do not serialize native V8 operation tokens or synchronously RPC into a blocked same actor. No execution has occurred.

## Cross-agent specification reconciliation

WHATWG HTML “beginning navigation” explicitly continues synchronously only when the surrounding agent equals the target active document's relevant agent; otherwise it queues a navigation-and-traversal task on the target active Window. The earlier proposal to require a synchronous remote admission/consume RPC pair is superseded by this requirement. Complete integration must route immutable source snapshots and selected navigable identity to the destination task, then perform admission there once. Same-actor reentrancy still must remain synchronous.

The same algorithm fires a cross-document navigate event only for a same origin-domain source, a noninitial target document, and a fetch-scheme URL. The fragment path precedes that gate. Native admission now skips cross-origin/non-fetch cross-document events while preserving hidden native revision custody, fragment admission and download handling. Parent script/service source metadata now carries authenticated origin identity, and the related-window receiver consumes it instead of treating a remote source as the destination. Regression sources cover origin gating, fragment cancellation, source identity and revision supersession. Domain-relaxation provenance and complete remote default-action dispatch/custody remain review items. No runtime validation.

## September 17 destination task integration

Accepted links now retain their signed Document provenance. Parent-selected remote link loads enqueue NavigateSelectedDocumentWindow with the captured frame connection (or root), source snapshot, referrer policy and involvement. The destination resolves its current document, authenticates the retained source, obtains destination-bound script authority and uses native Navigation admission. An unmaterialized initial blank root starts the normal nonblocking loader directly, with replacement history; it does not fabricate an intermediate document load or Navigation event. Parent queue outcomes identify admission, not full load completion. Worker protocol 16 includes this command and initial-start response.

Generated regression sources cover source retirement, destination binding, origin/referrer preservation, tampering and wire payload roundtrip. Remaining source work includes remote visible source-element/FormData custody, form NavigateEvent routing, the exact source-task enqueue point and callback/lifecycle reconciliation. No runtime validation has occurred.

Remote pages retain the inventory request. `PageOpened.selected_frame` returns the selected descendant; the local consumer retains parent document and connection identity and resolves the current document in that same frame. Missing local selections are discarded rather than converted into remote requests or root navigation. The authored bridge replaces supplied inventory with its own native snapshot and strips receipt/frame responses. Context protocol 48 and agent IPC 17 carry this generation change; worker protocol stays 16.
