## Recent integrations that change the old status

- Prefetch: native preload scheduling now handles `rel=prefetch` independently of image `as`, preserves document output URL encoding/referrer, keeps a tracked target and retained load/error receipt, drains arbitrary bytes without parsing them, and retires late streams. Parent ordinary Fetch supplies service-worker interception with an empty destination; native `Sec-Purpose` is inserted after header filtering on each hop. Standalone shares its ordinary Fetch/cache/cleanup engine with empty metadata and dedicated Prefetch CSP. Source regressions cover terminal arbitrary bytes, no script execution/decode, removal/late abort, metadata/purpose/policy and invalid native admission.
- Module delivery: loading's final graph consumer reconciliation and typed failure ledger replace the older open-root-init language for those actual callers. Existing map/SRI/TLA semantics remain authoritative.
- Streaming HTML: source scope includes token-level sanitizer admission, typed DOMString provenance, retained parser mutation/EOF state, template-for/PI patching, buffered external-template publication, captured options, and retained native script readiness. Automation owns final blocking-script ordering; do not duplicate that owner.
- Origin: parent/Agent/standalone/worker/script/frame/top-navigation producers now call the shared method/taint/referrer helper where applicable. WebSocket Origin remains its own mandatory handshake rule.
