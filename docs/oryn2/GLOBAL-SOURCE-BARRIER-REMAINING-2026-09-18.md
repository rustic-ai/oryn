## Barrier interpretation

The generation validator checks declarations and file identities. It cannot
prove that a cited function covers every parent algorithm or that its regression
is sufficient. The lane caller/disposition reconciliation supplies that semantic
review; the validator must not substitute for it. Conversely, unchecked runtime
acceptance rows do not demonstrate missing source. Once actual source/caller/
regression obligations are closed, deferred execution is precisely the next
phase of the user's instruction, rather than a reason to keep generating code
indefinitely.
